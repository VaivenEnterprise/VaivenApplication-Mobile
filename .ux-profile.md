# UX Profile

Generated by `setup-ui-ux-skills` (2026-11-10). All UI/UX skills in this project read this file before changing layout, copy, or interaction.

> Proyecto móvil (Expo / React Native). Donde una skill habla de CSS o de 375/1280 px, se aplica su equivalente nativo: estilos de `StyleSheet`, *tokens* de `src/theme` y pruebas en pantalla chica y grande. **Los tokens y la constitución (Art. VII) mandan sobre este perfil si chocan.**

## Aesthetic reference

- **Fidelidad al diseño de referencia (prioridad máxima):** la esencia de la propuesta de Stitch (`docs/diseno/referencia/`) se conserva: composición de cada pantalla, jerarquía, paleta terracota/verde/crema, tipografía, tarjetas y esquinas redondeadas, tono cercano. Las mejoras son ajustes puntuales (espaciado, contraste, estados, accesibilidad, microcopy), no un rediseño. Ante la duda entre «mejorar» y «parecerse a la referencia», gana la referencia. Cambios que se alejen de ella se proponen antes de hacerlos.

- **Standard:** Apple Native
- **Notes:** Espaciado generoso, radios unificados, transiciones fluidas y paleta neutra. Base de color ya definida (D-119): terracota `#C24E24`, verde `#1B7A57`, crema `#FAF6F0`, Plus Jakarta Sans. Solo se usan valores de `src/theme/tokens.ts`.

## Banned anti-aesthetics

- Glassmorphism / desenfoque sin borde de alto contraste
- Píldoras pastel flotantes para metadatos ordinarios
- Degradados decorativos arbitrarios y bordes neón (los degradados actuales de fondo y de `SlotPlaceholder` se revisan y simplifican)
- Degradados arcoíris en botones principales
- Ilustraciones caricaturescas en estados vacíos
- Scrolls anidados e íconos en exceso dentro de inputs

## Accessibility target

- **Level:** WCAG 2.1 AA
- **Contrast:** Texto normal > 4.5:1; texto grande y bordes > 3:1
- **Touch / focus:** Destinos táctiles de al menos 44 pt (`sizes.touch.minSize`); etiqueta accesible en todo control; tres estados (cargando, vacío, error) en cada pantalla con datos

## Brand tone and microcopy voice

- **Voice:** Warm & Humancentric
- **Capitalization:** Sentence case for UI copy and buttons
- **Notes:** Español de México, claro y breve, tuteo («Revisa tus datos»). Verbo primero en los botones. Los errores nunca culpan a la persona y ofrecen salida. Todo texto visible vive en `src/i18n` (Art. V).

## Icon library

- **Library:** Ionicons (estilo outline)
- **Package / path:** `@expo/vector-icons`, siempre a través de `src/components/ui/AppIcon.tsx`
- **Notes:** Una sola librería; sin emojis como íconos; los nombres nuevos se agregan al mapa de `AppIcon`.

## Agent rules

1. Read this profile before creating or editing any UI or microcopy.
2. Prefer skills by task: new page → `page-patterns` (name the pattern before markup); layout → `viewports` (adaptado: probar en 360×640 y en un teléfono grande, sin desbordes); forms → `forms`; overlays → `surfaces`; loaders → `loaders`; empty views → `empty-states`; motion → `motion`. Before finishing UI, run `ux-audit`.
3. Use only the recorded icon library. Do not mix icon sets or use emoji as UI icons.
4. Never introduce items on the banned list.
4b. Do not alter the essence of the reference design (see Aesthetic reference); only targeted improvements.
5. Destructive actions always use an explicit confirmation dialog.
