# Seguridad

Reporta vulnerabilidades mediante la opción privada de GitHub Security Advisories cuando esté habilitada, o por correo a vaivenedeltrabajo@gmail.com. No abras issues públicos con secretos o detalles explotables.

La rama main contiene versiones publicables; develop integra cambios validados. Los reportes se revisan para ambas ramas. Nunca adjuntes datos personales, contraseñas ni tokens reales.
